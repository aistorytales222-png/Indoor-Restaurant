# Indoor Restaurant website
1. Put images in public/images (names in PUT-IMAGES-HERE.txt)
2. npm install
3. npm start   -> http://localhost:3000
4. Bookings: http://localhost:3000/admin.html  (key = ADMIN_KEY env, default "change-me")
Deploy: Render/Railway, set ADMIN_KEY. Note: use a persistent disk or a database in production, free hosts wipe data/reservations.json.
